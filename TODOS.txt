1. Fix the paper's placeholder fields first

Replace [university-domain] with your real HUA email domain
Replace [org] in the GitHub URL once you create the repo (see below)
2. Create a new public GitHub repo for the artifact

Create a new repo on GitHub (e.g. hua-vehicular-mec-offloading or cloudnet2026-artifact)
The cloudnet/ folder should be the root of that repo (not a subdirectory), because the README says git clone <url> && cd cloudnet
Push it and create a release tagged v1.0.0
Update the URL in paper.tex line ~163
3. Upload the dataset to Zenodo (for the DOI)

Go to zenodo.org → New Upload
Upload cloudnet/data/network_dataset.csv
Title: same as paper, authors: same, license: MIT
You can Reserve a DOI before actually publishing (useful: DOI exists for the submission but data publishes later)
Add the DOI to paper.tex in the Dataset section replacing "upon acceptance"
4. Compile the PDF

You need IEEEtran.cls — download from CTAN and put it next to paper.tex
Then run inside cloudnet/:

pdflatex paper && pdflatex paper
Check it's exactly 2 pages before submitting
5. Submit the PDF to IEEE CloudNet 2026

Go to the submission system linked from the conference website (usually EDAS)
Submit the 2-page PDF
Make sure the GitHub repo and Zenodo DOI are both live/accessible by the time reviewers check
That's it — in order:

Fix emails + GitHub URL in paper.tex
Push cloudnet/ contents to a new public GitHub repo → tag v1.0.0
Upload dataset to Zenodo → get DOI → update paper.tex
Run pdflatex twice → verify 2 pages
Submit PDF to CloudNet 2026 system
